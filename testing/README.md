# Проверка прав преподавателя

Этот набор проверяет разграничение доступа преподавателя в Student Attendance API.

## Что проверяется

- преподаватель видит только назначенные ему группы;
- преподаватель может просматривать студентов, занятия и статистику своей группы;
- преподаватель может изменять посещаемость своей группы;
- преподаватель не может читать или изменять данные чужой группы;
- преподаватель не может выполнять административные операции.

## Запуск локально

Из корня репозитория запустите API и PostgreSQL:

```bash
docker compose up --build -d
```

Установка тестовых зависимостей:

```bash
cd backend
python -m pip install -r requirements-dev.txt
```

Запуск всех тестов:

```bash
python -m pytest -v
```

Запуск только проверок прав преподавателя:

```bash
python -m pytest tests/test_teacher_permissions.py -v
```

Тесты прав создают отдельную тестовую базу SQLite в памяти и выполняют запросы к реальному приложению FastAPI через TestClient. Они не используют данные рабочей PostgreSQL.

## Проверка работающего PostgreSQL

После запуска контейнеров из корня проекта:

```bash
docker compose ps
curl http://localhost:8000/health
curl http://localhost:8000/health/db
```

Ожидается HTTP 200 и JSON со статусом `ok` для API, а также `database: connected` для проверки БД.

> Не публикуйте рабочие пароли, токены, строки подключения или дампы базы данных в репозитории. Эндпоинт `/health/db` раскрывает количество записей и должен быть ограничен или защищён в публичном production-развёртывании.
