## Технологии

- Backend: Python, FastAPI, SQLAlchemy.
- База данных: PostgreSQL 16.
- Mobile: Kotlin, Jetpack Compose, Android Studio.
- Инфраструктура: Docker, Docker Compose.
- Тестирование: pytest, GitHub Actions.
- ML: конкретную функцию определяет Сурков Г.

## Организация работы

- `main` — стабильная основная ветка проекта.
- `develop` — ветка для объединения изменений.
- `feature/*` — ветки для разработки отдельных задач.
- `docs/*` — ветки для изменения документации.
- Все изменения проходят через Pull Request.
- Перед объединением проверяются результаты GitHub Actions.

## Обмен ролями

Порядок и даты обмена ролями обсуждаются командой. Изменения распределения обязанностей фиксируются в документации после согласования.
