# Модель риска по посещаемости

`GET /risk?group_id=1&student_id=1` возвращает оценку риска для конкретного студента. Если убрать `student_id`, API возвращает оценки для доступных студентов группы, у которых есть отметки за последние восемь недель.

Логистическая регрессия использует три признака за восемь недель:

- долю отметок `present` и `late` от всех сохранённых отметок;
- максимальное число последовательных `absent`;
- число отметок `late`.

Положительный класс означает четыре и более пропуска в следующих восьми смоделированных занятиях. Генератор формирует 1 000 синтетических историй. Первые 800 после перемешивания используются для обучения, остальные 200 для оценки. При пороге классификации 0,5 получены **accuracy 0,76** и **F1 0,6066**. Эти метрики описывают синтетические данные.

Уровни в API: `high` при вероятности от 0,5, `medium` от 0,3 до 0,5, `low` ниже 0,3. Модель обучается один раз при первом запросе в процессе API и кешируется. Команда для повторного расчёта метрик из каталога `backend`:

```powershell
python -m app.risk_model
```
