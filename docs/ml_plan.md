
# ML-функция проекта

## Название
Прогноз студентов группы риска по посещаемости.

## Цель
Определять студентов, у которых повышен риск пропусков занятий в ближайшее время.

## Какие данные используются
- Общий процент посещаемости.
- Количество пропусков.
- Количество пропусков подряд.
- Посещаемость за последние недели.

## Планируемая модель
Логистическая регрессия для классификации риска.

## Откуда берём данные
На первом этапе — синтетические данные, сгенерированные Python-скриптом.

## Ожидаемый результат
Система определяет студентов с повышенным риском и отображает их в приложении.

## Ограничение
Модель на искусственных данных будет демонстрационной и не сможет считаться надёжным прогнозом для реальных студентов.
