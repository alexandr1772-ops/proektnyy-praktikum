# Демонстрация DevOps-части

## Чистый запуск

Из корня репозитория:

```bash
docker compose down --volumes
docker compose up --build
```

Для первой демонстрации достаточно второй команды; первая нужна только для удаления данных предыдущего запуска.

## Что показать

1. Открыть `http://localhost:8000/health` — API отвечает `{"status":"ok"}`.
2. Открыть `http://localhost:8000/health/db` — статус БД `connected`, счётчики записей больше нуля.
3. Открыть `http://localhost:8000/students` — уже есть демонстрационные студенты.
4. Открыть `http://localhost:8000/docs` и через Swagger UI создать студента, занятие и отметку посещаемости.
5. Повторно вызвать `GET /attendance` и показать сохранённую запись.

## Проверка с телефона

Ноутбук и телефон должны быть в одной Wi-Fi сети. Порт Compose опубликован как `8000:8000`, поэтому на телефоне нужно открыть:

```text
http://<локальный-IP-ноутбука>:8000/health
```

Если страница не открывается, проверить локальный IPv4-адрес, правило брандмауэра для TCP 8000 и отсутствие гостевой изоляции устройств в Wi-Fi сети.

## Секреты

Реальные логины и пароли находятся только в локальном `.env`. В GitHub хранится `.env.example`, а `.env` исключён через `.gitignore`.
